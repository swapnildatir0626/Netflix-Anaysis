# Netflix Data Analysis Using MySQL

## 1. Project Overview

This project explores Netflix movies and TV shows using MySQL. The goal is to analyze the content available on Netflix, identify patterns in its catalog, and practice SQL querying, data cleaning, and data analysis.

## 2. Dataset Information

The dataset contains information about Netflix titles, including:

- Title ID, title, and type (Movie or TV Show)
- Description, release year, and age certification
- Runtime and number of seasons
- Genres and production countries
- IMDb ratings and votes
- TMDB popularity and votes

A separate credits dataset contains information about people associated with titles.

## 3. Tools Used

- **MySQL:** Database management and data analysis
- **MySQL Workbench:** Writing and executing SQL queries
- **GitHub:** Version control and project documentation

## 4. Analysis Performed

The SQL script includes database setup, data preparation, cleaning, and analytical queries to explore the Netflix catalog.

The analysis covers topics such as:

- Movies and TV shows available on Netflix
- Content release years and runtime
- Genres and production countries
- Ratings and audience engagement
- Other patterns in the Netflix catalog

## 5. Project Structure

- `Netflix_SQL_Analysis.sql` - SQL script containing database setup, cleaning, and analysis queries.
- `Netflix_Analysis_Project_Summary_Concise.pdf` - Summary of the project, workflow, and analysis.
- `README.md` - Project documentation.

## 6. How to Run the Project

1. Install MySQL and open MySQL Workbench.
2. Open `Netflix_SQL_Analysis.sql`.
3. Review the database and table setup instructions in the script.
4. Ensure the required dataset files are available at the locations

## 7. Project Goals

This project demonstrates practical SQL skills, including database setup, data cleaning, filtering, aggregation, joins, and analytical querying.
